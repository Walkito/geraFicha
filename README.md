Gera Ficha API

Este repositório se refere ao Projeto Gera Ficha, onde o objetivo principal é gerar fichas automáticas para RPG de Mesa, um estilo de jogo onde é necessário a todo momento
construir personagems. Tendo em vista este procedimento, o Gera Ficha é um projeto onde com poucos cliques você consegue criar uma ficha em PDF para o seu personagem.

Este repositório contem todo o Back End da aplicação. Ela foi feita em Java com Spring Boot e banco de dados MySQL.
